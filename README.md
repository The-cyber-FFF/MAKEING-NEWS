# arknights 头条生成器

一个纯前端、零依赖的「仿头条」图片生成器。输入标题和引言、替换右侧图片，即可实时排版并导出 **2560 × 2076 PNG**。

> 非官方粉丝项目，与 Hypergryph / 鹰角网络、NVIDIA 没有任何关联。

![界面预览](docs/preview.webp)

![生成样张](docs/sample-output.webp)

## 功能

- 两处文字输入：标题、引言
- 左侧人物素材固定，右侧图片点击或拖拽替换
- 标题在第一个逗号后自动换行，文字过长时自动缩小
- 引言自动缩放，最多两行
- 日期自动使用当天日期
- 2× 高清 PNG 导出
- 无后端、无数据库、无第三方依赖
- 图片仅在浏览器本地处理，不会上传

## 使用

直接双击 `index.html`，用 Chrome 或 Edge 打开。

1. 填写标题和引言。
2. 点击右侧图片区域，或把图片拖进去，替换默认金龙。
3. 点击“生成图片”，下载 PNG。

## 本地预览

不启动服务器也可以直接打开 `index.html`。如果需要通过本地地址访问：

```bash
python -m http.server 8080
```

然后打开 `http://localhost:8080/`。

## 部署

这是一个纯静态页面。将以下文件放在同一个目录：

```text
index.html
styles.css
app.js
assets.js
```

把整个目录上传到任意静态网站服务即可，不需要构建步骤。

### GitHub Pages

1. 将仓库推送到 GitHub。
2. 打开仓库的 **Settings → Pages**。
3. **Source** 选择 **Deploy from a branch**。
4. 分支选择 `main`，目录选择 `/ (root)`，保存。
5. 稍等片刻，页面会部署到 `https://<用户名>.github.io/<仓库名>/`。

## 实现说明

排版和导出全部由浏览器原生 Canvas 2D 完成，没有引入框架或第三方库。画面按 1280 × 1038 的逻辑尺寸排版，导出时以 2× 比例重新绘制，得到 2560 × 2076 PNG。

默认图片被内嵌为 Data URI，所以直接以 `file://` 打开页面也能完成绘制和下载，不会遇到跨域污染画布的问题。
